# agent-sandbox

Песочница для демонстраций AI-агента. Это статический лендинг **вымышленного**
продукта Orbit — здесь нет ничего боевого, любые изменения и слияния безопасны.

Назначение: показывать сценарий «попроси агента поправить сайт → он делает PR →
мержишь кнопкой прямо из чата». Ни с каким продакшеном, CI или деплоем не связан.

## Файлы

- `index.html` — страница лендинга
- `styles.css` — стили

## Идеи для демо

Попросите агента, например:
- «поправь опечатку/текст на лендинге»
- «поменяй цену на тарифе Команда на 690 ₽»
- «добавь блок с отзывами»
- «сделай кнопку CTA заметнее»

Агент создаёт ветку и pull request, а в чат приходит дифф с кнопками
Merge / Close.
